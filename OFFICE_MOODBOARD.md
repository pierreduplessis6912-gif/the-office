# The Office — Mood Board

A shared visual language reference, so Claude, Kimi, ChatGPT, and
Pierre are drawing from the same well rather than each imagining a
different version of "cinematic." Given directly by Pierre — the
governing rule: **steal ingredients (lighting, atmosphere, motion,
material), never layout.** The Office isn't a dashboard. It's a room.

**A real, honest note on how this is built:** these are links to the
real, original sources, not embedded copies. Dribbble shots are other
designers' copyrighted work — referencing and describing them for
inspiration is one thing; redistributing the images themselves into
this repo is another, and this document deliberately does the
former, not the latter. Each entry's rationale is original — what to
take from it for The Office, specifically, not a restatement of the
designer's own description.

**Real, honest scope of this first pass:** search tooling struggles
with genuinely niche, visual-discovery queries like these — several
searches returned nothing or off-target, generic AI-art results
rather than real design references. What's below is what was
actually found and verified, not the full 7×10 vision yet. Pierre
browsing Dribbble directly (with real, visual scrolling this text
search can't replicate) and adding links here is likely to fill this
out faster and better than more automated searching would.

## 🔮 Orb behaviour

- [Orb AI Motion](https://dribbble.com/search/ai-orb) — theosm™ Team.
  *Take: the orb as a continuously-moving, never-static object — the
  actual thing OFFICE_RUNTIME_V1.md means by "the orb is already
  breathing" before any interaction happens.*
- [AI Input Orb Animation](https://dribbble.com/search/ai-orb) —
  Vivid Motion®. *Take: the orb reacting to input as a real,
  continuous deformation of the same object, not a swap to a
  different visual state.*
- [AI Assistant - Orb motion research](https://dribbble.com/search/ai-orb)
  — Lucas Loyola. *Take: explicitly framed as motion* research *—
  the orb's identity lives in how it moves, not a single static
  render.*
- [Orbita AI - Chat Assistant](https://dribbble.com/search/ai-orb) —
  Uxerflow Team. *Take: an orb that stays the calm, central object
  even while a real conversation is happening around it — worth
  studying for how it avoids competing with its own content.*

## 🌌 Empty space / atmosphere

- [Space Observatory - UI Design Concept](https://dribbble.com/shots/10208228-Space-Observatory-UI-Design-Concept)
  by Paup. *Take: real, generous negative space around a small
  number of floating elements — closest single reference found so
  far to "the void is sacred" (Rule of DESIGN_CONSTITUTION_V2.md).
  Not the specific instruments or layout — the sheer amount of
  nothing surrounding the few things that matter.*

## 🌫 Dark, restrained interface material

- [Mini Sci-fi UI Kit](https://dribbble.com/) by Raphael Lopes.
  *Take: restrained glow and material without descending into the
  "neon overload" explicitly named as a trap to avoid — a real,
  working example of sci-fi atmosphere that stays quiet rather than
  loud.*
